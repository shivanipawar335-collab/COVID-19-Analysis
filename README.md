# COVID-19 Data Analysis Project

## Project Overview
This project analyzes COVID-19 data using Python.

## Objectives
- Analyze COVID-19 cases.
- Analyze recovered patients.
- Analyze death records.
- Compare country-wise COVID-19 data.
- Visualize COVID-19 trends.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
COVID-19 dataset containing country, population, cases, recovered, deaths and tests.

## Data Analysis
- Data Cleaning
- Missing Value Handling
- Country-wise Analysis
- Monthly Analysis
- Correlation Analysis

## Visualizations
- Top 10 Countries COVID Cases
- Top 10 Countries Deaths
- Top 10 Countries Recovered
- Monthly COVID Cases
- Correlation Heatmap

## Conclusion
This project helps understand COVID-19 data through Python analysis and visualization.
